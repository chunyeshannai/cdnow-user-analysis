# CDNow 网站用户消费行为分析

基于 1997.01–1998.06 期间 23,570 名用户的 69,659 条 CD 购买明细，从经营趋势、用户价值分层、复购行为三个维度挖掘消费规律，并用假设检验验证关键结论，最终输出可落地的运营建议。

📄 完整分析报告见 [report.md](./report.md)

## 数据说明

- 数据文件：`CDNOW.txt`（随仓库提供）
- 记录数：69,659 条交易明细，23,570 名用户
- 时间范围：1997-01-01 至 1998-06-30
- 字段：用户ID（user_id）、购买日期（order_dt）、订单数（order_num）、订单金额（order_amount）
- 数据质量：无缺失值；0 元订单 80 条（占比 0.11%），经核查均为单件订单，推测为赠品/促销单，因不影响金额加总予以保留

## 核心结论

1. **经营层面"重拉新、轻留存"**：1997 年 Q1 订单量与销售额冲高后迅速回落，且两者趋势高度一致，说明平台为客流驱动，缺乏留存承接能力
2. **营收高度依赖头部，但腰部有真实付费能力**：前 10% 用户贡献 50.9% 营收，排名后 50% 用户仅贡献 10.4%；第 10%~50% 的腰部用户贡献约 39%，具备向上培育空间
3. **过半用户止步于首购**：复购率 49.48%，用户两极分化明显，首购后的承接机制基本空白
4. **复购用户价值显著更高（假设检验验证）**：Welch's 独立样本 t 检验显示复购用户客单价显著高于一次性用户（35.05 vs 30.23，t = 12.73，p < 0.001）；卡方检验显示高/低消费用户的复购率存在显著差异（χ² = 6926.79，p < 0.001）
5. **留存指标长期无改善**：月度回购率稳定在 25%~35% 锯齿波动，再无上升趋势

## 业务建议

- 建立新客 30 天召回机制，促成二单
- 对约 1,000 名高价值沉睡用户做分层专项召回
- 将月度回购率纳入留存侧核心监控指标

## 如何运行

环境：Python 3.8+，依赖 pandas、numpy、matplotlib、scipy

```bash
pip install pandas numpy matplotlib scipy
python analyse.py
```

## 技术栈

`pandas`（数据清洗、分组聚合、透视表）｜ `scipy.stats`（Welch's t 检验、卡方检验）｜ `matplotlib`（数据可视化）｜ RFM 用户分层、复购率/回购率分析
